About This Project

Urban Myths Explorer is a web-based application designed to allow users to search, explore, and read detailed information about famous urban myths and legends from around the world. The goal of this project is to present well-known urban myths—such as Bigfoot, the Jersey Devil, and Bloody Mary—in an organized and engaging way. Each myth includes a short preview on the dashboard and a dedicated detail page where users can read an in-depth description covering origins, characteristics, cultural significance, and why the myth continues to exist today.

The application allows users to browse urban myths through a clean dashboard interface, use a search bar to quickly find specific legends, and click “Read More” to access a full-length explanation of each myth. Urban Myths Explorer combines storytelling with technical implementation, showing how web applications can be used to present rich, text-heavy content in an accessible and visually appealing way.
